# AntiGray Roblox
Простенький батник, который с помошью запроса айпи и изменения файла hosts чинит у многих серый экран в Roblox (основано на решении из ветки в zapret-discord-youtube, но код и всё прочее моё, хоть и на ИИ.
Функции: обход с выборов айпи которое будет действовать, автозапуск с номером айпи которое работает, отключение автозапуска, запуск обхода для ленивых.
